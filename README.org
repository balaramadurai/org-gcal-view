# org-gcal-view

A Google Calendar-inspired interface for Emacs, built on top of `org-agenda-files`.

** Features
:PROPERTIES:
:CUSTOM_ID: features
:END:
- 📅 Day, week, and month views with Google Calendar keyboard shortcuts
- 🗓️ Day view with time grid, lane-packed event blocks and hairlines
- 📊 Month view with event dots
- 📋 Week view shows overlapping events with "+n" indicator (hover to see all)
- 🎯 Focus navigation between events / month day cells, mouse support -
  moving between events shows the same file/outline-path breadcrumb
  org-agenda shows in the echo area, e.g. ~spirelia.org/Meetings~
- ⏱️ Clocking integration: shows 🕐HH:MM-HH:MM clock times on events
- ✏️ Event creation and editing straight from the calendar view
- 🎨 Per-CATEGORY block colors, and a Work/Personal/all filter cycle
- ❌ CANCELLED events shown with red strikethrough, DONE events with default strikethrough

** Configuration
:PROPERTIES:
:CUSTOM_ID: configuration
:END:
- ~org-gcal-view-category-colors~: alist of Org CATEGORY -> hex color.
  When an event's CATEGORY has an entry here, that color is used for its
  block and stripe (with an automatically chosen readable text color)
  instead of the default tags-based work/life/habit coloring.
  #+begin_src emacs-lisp
  (setq org-gcal-view-category-colors
        '(("Work" . "#3b82f6")
          ("Family" . "#aed581")
          ("Entrepreneur" . "#4CAF50")))
  #+end_src
- ~org-gcal-view-work-categories~: list of CATEGORY values that count as
  Work for the ~P~ filter below; every other CATEGORY counts as Personal.

** Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:
- ~M-x org-gcal-view-day-view~ / ~org-gcal-view-week-view~ / ~org-gcal-view-month-view~
- Global keys: ~C-c g d~ (day), ~C-c g w~ (week), ~C-c g m~ (month)
- In an org-agenda buffer: ~C-c C-c~ (day), ~C-c C-w~ (week), ~C-c C-m~ (month)

Inside the calendar buffer: ~d~/~w~/~m~ switch views, ~t~ jumps to today,
~j~ opens a calendar popup to jump to any date, ~k~/~n~/~p~/~f~/~b~ move
forward/back a day/week/month. ~<up>~/~<down>~ move focus between events
(restricted to the same day, in week view); in week view ~<left>~/~<right>~
instead move focus to an event on the adjacent day, while in day/month view
they move forward/back like ~n~/~p~. ~TAB~ previews an event in a split,
~RET~ opens it, ~/~ searches titles, ~i~/~o~ clock in/out, ~c~ creates a new
event, ~P~ cycles the Work/Personal/all filter (see
~org-gcal-view-work-categories~ above), ~s~ saves all Org buffers,
~q~ quits.
